## Description
<p>
  Le but du projet est la création d'une application de modélisation 3D avec une bibliothèque graphique 2D (Pygame), 
  qui permet la modélisation d'un cube. Bien que des formes plus complexes pourront s'ajouter par la suite.
  Le projet est codé en Python, Programmation Orientée Objet.</BR>
</p>
