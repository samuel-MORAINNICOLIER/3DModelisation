# 3D-Modelisation

## Auteur
### Samuel MORAIN-NICOLIER
  
> Github : https://github.com/samuel-MORAINNICOLIER

## Description
<p>
  Le but du projet est la création d'une application de modélisation 3D avec une bibliothèque graphique 2D (Pygame), 
  qui permet la modélisation d'un cube. Bien que des formes plus complexes pourront s'ajouter par la suite.
  Le projet est codé en Python, Programmation Orientée Objet.</BR>
</p>

## Installation du projet
   > Avoir Python et Pygame d'installé sur son pc ou son environnement </BR>
   > Python : https://www.python.org/downloads/ </BR>
   > Pygame : https://pypi.org/project/pygame/ </BR>
   > \> git clone https://github.com/samuel-MORAINNICOLIER/3DModelisation.git </BR>
   > \> cd 3DModelisation </BR>

## Lancer le projet
<p>
   Se rendre dans le répertoire Test3D et lancer le fichier Test.py (/Test3D/Test.py)
</p>

## Commandes
<p>
   Faire tourner le cube avec les touches 1, 2 et 3 du clavier, pas le pavé numérique, 
   pour, respectivement, les axes x, y et z.
</p>
